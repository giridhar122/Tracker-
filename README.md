# GymTracker 🏋️‍♂️

A fast, streamlined check-in and membership validation system for fitness centers. Designed for a seamless **"Scan & Go"** entry experience, automated attendance tracking, and real-time membership verification.

---

## 📌 Features

* **Scan & Go Check-In**: Instant entry logging via QR code or barcode scanning.
* **Live Membership Verification**: Automatically checks membership status, expiration dates, and tier access on scan.
* **Attendance Tracking**: Real-time logging of member check-in/check-out timestamps and peak hour analytics.
* **Admin Dashboard**: Member management, subscription renewal alerts, and entry history logs.
* **Access Control Alerts**: Instant visual feedback (access granted, expired plan, payment due).

---

## 🛠️ Tech Stack

* **Frontend**: HTML5 / React / Tailwind CSS
* **Backend**: Node.js / Express or Python / FastAPI
* **Database**: PostgreSQL / MongoDB
* **Scanner Integration**: Web-based QR/Barcode Scanner (e.g., `html5-qrcode` / ZXing)
